## 🚀 Fonctionnalités Avancées (Pigeon-Tech™ v1.1.0)

* **50 Pigeons d'Élite** : Des pigeons parisiens mangeurs de viennoiseries aux pigeons impériaux couronnés. Toutes les photos sont 100% réelles.
* **Barre Blanche Épurée & Auto-Hide AFK** : Une barre de contrôle blanche style dock moderne qui s'estompe automatiquement au bout de quelques secondes d'inactivité (mode contemplation cinéma).
* **Musique de Fond Envoûtante** : Une mélodie apaisante pour accompagner vos séances de contemplation aviaire.
* **Contrôleur de Volume & Mute** : Baisse le son ou coupe-le d'un clic.
* **Navigation Tactile & Clavier** :
  * Flèche Droite / Espace : Pigeon suivant
  * Flèche Gauche : Pigeon précédent
  * Touche M : Couper / Activer le son
  * Échap : Fermer les fenêtres
* **Modale Contact & Réseaux Sociaux Pinou007** : Retrouvez tous les réseaux de Pinou007 (YouTube, Instagram, Twitter, Discord, GitHub, Spotify, Site Web).
* **Support Multi-Plateforme Complet** : Windows, Android et Linux.

## 🛠️ Pour les Éleveurs & Développeurs

```bash
# Installer les dépendances
npm install

# Lancer la version Desktop Electron en mode dev
npm start

# Compiler l'installateur Windows (.exe)
npm run build:pc

# Compiler pour Linux (.tar.gz)
npm run build:linux

# Compiler l'application mobile Android (.apk signé)
npm run build:mobile

# Recompiler tout d'un coup (PC + Linux + Mobile)
npm run build:all
```
