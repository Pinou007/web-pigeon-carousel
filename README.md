# 🐦 Le Paradis des Pigeons (Pigon.Pinou007.fr) 🥖

> *"Pourquoi contempler l'univers quand on peut regarder 50 vrais pigeons en boucle avec une musique divine ?"* — Un grand philosophe de caniveau (probablement Pinou007).

Bienvenue sur le projet le plus essentiel de l'histoire du web moderne : **une galerie infinie de magnifiques pigeons 100% authentiques**, sans trucage, sans IA, juste de la vraie plume, du vrai regard hébété et du pur roucoulement.

Accessible en direct sur le web : **[pigeon.pinou007.fr](https://pigeon.pinou007.fr)** *(ou [pigon.pinou007.fr](https://pigeon.pinou007.fr))*.

## 🚀 Fonctionnalités Avancées (Pigeon-Tech™)

* **50 Pigeons d'Élite** : Des pigeons parisiens mangeurs de viennoiseries aux pigeons impériaux couronnés. Toutes les photos sont 100% réelles, garanties zéro hallucination artificielle.
* **Musique de Fond Envoûtante** : Une mélodie apaisante pour accompagner vos séances de contemplation aviaire.
* **Contrôleur de Volume & Mute** : Baisse le son si ton patron arrive, monte le son à 100% si tu es chez toi pour réveiller les oiseaux du quartier.
* **Navigation Tactile & Clavier** :
  * Flèche Droite / Espace : Pigeon suivant
  * Flèche Gauche : Pigeon précédent
  * Touche M : Couper / Activer le son
  * Échap : Fermer les fenêtres
* **Zéro fioriture inutile** : Pas d'effet chelou, pas de texte qui gâche la vue, juste le pigeon au centre de votre vie.
* **Bouton Contact VIP** : Une envie pressante de parler de pigeons ? Clique sur contact pour envoyer un mot doux à `contact@pinou007.fr`.
* **QR Code Grand Format** : Scanne-le en mangeant un bout de baguette pour emmener les pigeons partout sur ton téléphone.

## 🛠️ Pour les Éleveurs & Développeurs

Pour lancer ou recompiler la bête chez toi :

```bash
# Installer les dépendances
npm install

# Lancer la version Desktop Electron en mode dev
npm start

# Compiler l'installateur Windows (.exe)
npm run build:pc

# Compiler l'application mobile Android (.apk signé)
npm run build:mobile

# Recompiler tout d'un coup (PC + Mobile)
npm run build:all
```
